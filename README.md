# FixIt – Sistema de Gestión de Servicios Técnicos

Sistema web pensado para un pequeño taller de reparación de computadoras y dispositivos electrónicos. Permite registrar clientes y equipos, crear órdenes de servicio con comprobante, asignar técnicos, actualizar el estado de las reparaciones (Recibido, En diagnóstico, En reparación, Listo y Entregado) y consultar el historial de servicios por cliente y por equipo. Contempla tres roles de usuario: administrador, recepcionista y técnico.

Este es un proyecto simulado: lo que se evidencia es la planificación y la gestión del proyecto (metodología, alcance, cronograma, riesgos, comunicación y configuración de herramientas), no la programación completa del sistema.

## Metodología

Se utiliza una metodología **ágil: Scrum adaptado con tablero Kanban**. El proyecto dura 8 semanas, organizadas en 4 sprints de 2 semanas. El tablero de Trello tiene las listas Backlog, Por hacer, En progreso, En revisión y Hecho. Una función se considera terminada cuando está programada, probada, subida a GitHub y revisada por otro integrante.

Herramientas: Trello, GitHub, Microsoft Teams, Google Drive, WhatsApp y Microsoft Word.

## Estructura del repositorio

- `docs/`: documentación del proyecto (informe, diagramas y evidencias)
- `src/`: código fuente
- `tests/`: pruebas

## Convenciones de trabajo

- **Ramas:** una por función o tarea, por ejemplo `RF01-clientes` o `docs-planificacion`.
- **Commits:** el mensaje empieza con el código del requisito o el tipo de cambio, por ejemplo `RF01: formulario de clientes` o `docs: agrega informe de planificación`.
